# 세션 프롬프트 만들기

프롬프트는 문서에서 조립한다. 채팅에서 새로 쓰지 않는다 — 문서가 SSOT 이고, 조립본은 그 사본이다.

## 1. 무엇을 만들지 정한다

- `python .cld/harness/cld.py status` 로 다음 Phase 를 본다. 사용자가 지정했으면 그것을 따른다.
- 인수인계 맨 위 항목의 «다음 사람에게» 를 읽는다. 특히 «N. 독립 검증 — 이월 목록» 이 있으면 그 항목이 이번 세션에 실려야 한다.
- 마스터 플랜 결정 기록(§4)에 최근 사용자 결정이 있으면 «이번 세션» 에 반영한다(예: 순서 · 범위 · 방식).

## 2. Phase 절의 «이번 세션» 을 고친다

세션 프롬프트 문서의 `## <id>.` 절을 고친다. 고친 뒤 조립한다.

- 끝난 단계 · 이력 · 일화 · 중복을 걷는다(짧게 — 🟢 기준 약 120줄).
- ⓪ 착수 전 물을 것: 사용자 결정이 필요한 것만. 선택지 · 권고를 붙인다.
- 이월: 독립 검증 이월 목록의 항목을 번호로 싣는다(원문은 인수인계에 있다 — 여기에는 한 줄씩 · 가리키기만).
- 멈춤 조건: 값 불변 커밋이면 «게이트가 차이를 내면 멈추고 원인을 적는다(기준선 재포착 금지)».
- «이 세션에서 하지 않는 것» 에 다음 Phase 의 일을 적는다.
- `권고 모드:` 줄을 기준 ⓐ ~ ⓓ 로 다시 정한다. 근거를 한 줄 적는다.
- 머리(`cld-head`)는 열 줄 안쪽: 모드 · 이번 세션 한 줄 · 먼저 읽을 것 · 먼저 물을 것 · 🔴 멈춤 조건 · 🔴 금지 · 커밋 제목 꼴 · 블록 순서.

## 3. 조립

```
python .cld/harness/cld.py prompt build <id> --out <스크래치>/prompt_<id>.txt
```

- 하네스가 막는 것: 머리 열 줄 초과 · 🟢/🟡 프롬프트의 울트라코드 영문 낱말 · 🔴/🟡 인데 다중 에이전트 블록 없음 · 절 · 블록 누락.
- 막히면 문서를 고쳐 다시 조립한다. 조립본을 손으로 고치지 않는다.
- 사용자가 모드를 바꾸면 `--mode 🔴|🟡|🟢`.

## 4. 사용자에게 준다

- 메시지 첫 줄: «대상: <이 프롬프트를 붙일 세션 — 예: P3 구현 세션을 시작할 사용자 본인>».
- 권고 모드와 근거를 먼저 적는다(한두 문장). 모드는 사용자가 정한다.
- 프롬프트가 가리키는 문서 변경이 아직 커밋 전이면, 새 세션을 열기 전에 커밋하라고 적는다(명령 포함).
- 사용자가 «복사할 수 있게» 를 원하면 조립본 전문을 코드 블록(``````` 네 개 — 안에 ``` 가 있을 수 있다)으로 붙인다. 파일 경로도 준다.
- 문서를 고쳤으면 세션 프롬프트 문서 변경 이력에 한 줄 더하고, 커밋 명령을 준다.
