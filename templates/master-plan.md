## 2. Phase 순서와 게이트

🔴 **순번이 순서다.** Phase 이름은 한 번 정하면 바꾸지 않는다(과거 기록이 이름을 가리킨다). 순서를 바꾸면 순번만 고친다.

Phase 를 나누는 원칙:
- 한 Phase = 독립 세션 하나(또는 커밋 단계 여럿 — 표의 «세션» 칸에 적는다). 표 한 줄이 규모를 감추면 줄을 나눈다.
- 값이 바뀌는 커밋과 값이 안 바뀌는 커밋을 섞지 않는다. 값 불변 커밋은 게이트가 «차이 0» 으로 증명한다.
- 끄고도 출하 가능한 단위로 자른다(스위치 · 기본값 off). 근거가 안 닫힌 것은 끈 채로 출하한다.
- Phase 를 늘리지 않는다. 후속은 다음 예정 단계에 합치기부터 검토한다. 떼면 이유를 한 문장으로 적는다.

| 순번 | Phase | 무엇 | 게이트 | 세션 | 상태 |
|---|---|---|---|---|---|
| ① | P1 | | | 1 | 대기 |
